## What We Built
A new technique module `agent/techniques/t1046_network_service_scan.py` that:
- Scans 30 common ports on the target host
- Uses threading to run all scans in parallel
- Returns open ports with their service names

Registered the technique in `agent/main.py` (import + techniques dict).

## Concepts Learned

**Port scanning** — Probing IP addresses and port numbers to find open services. An open port means a service is listening and potentially accessible. Core to T1046 and tools like nmap.

**Well-known ports** — Standardized port assignments: 22=SSH, 80=HTTP, 443=HTTPS, 3306=MySQL, etc. Can be changed but conventionally followed.

**socket** — Python's built-in module for opening network connections. `connect_ex()` returns 0 if the port is open, non-zero if closed. `settimeout()` prevents hanging on unresponsive ports.

**Threading** — Running multiple port checks in parallel using `concurrent.futures.ThreadPoolExecutor`. Scanning 30 ports one at a time at 0.5s timeout = 15 seconds. With 50 threads in parallel = under 1 second.
