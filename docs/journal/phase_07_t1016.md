## What We Built
A new technique module `agent/techniques/t1016_network_config.py` that collects:
- DNS server addresses from `/etc/resolv.conf`
- Routing table from `/proc/net/route`
- Network interfaces and IP addresses via `subprocess` + `ip addr`

Registered the technique in `agent/main.py` (import + techniques dict).

## Concepts Learned

**DNS** — Domain Name System. Translates human-readable domain names (google.com) into IP addresses. The machine's configured DNS server is stored in `/etc/resolv.conf`. For an attacker, reading this file reveals the internal DNS server, which is often a router or domain controller.

**Routing table** — A map that tells the OS which direction to send network traffic. The default route (destination `0.0.0.0`) points to the gateway — your router. Read from `/proc/net/route`.

**Little-endian hex** — `/proc/net/route` stores IP addresses as hex values in little-endian byte order. Must reverse the bytes before converting to a dotted IP string.

**subprocess** — Python's built-in module for running shell commands and capturing output. Used here because `ip addr` output is easier to parse than the raw `/proc/net/` files for interface discovery.

**Subclass / inheritance** — `NetworkConfigDiscovery` inherits from `AttackTechnique`, which requires implementing `run()`. This is the same pattern used by every technique module.
