## What T1082 Collects

| Field | Source | Value on Pi |
|---|---|---|
| hostname | socket library | raspberrypi |
| os | platform library | Linux |
| os_version | platform library | Debian 1:6.6.20 |
| kernel | platform library | 6.6.20+rpt-rpi-2712 |
| architecture | platform library | aarch64 |
| python_version | platform library | 3.11.2 |
| memory total | /proc/meminfo | 8,241,616 KB (8GB) |
| memory available | /proc/meminfo | ~7.7GB |
| uptime_seconds | /proc/uptime | varies |

## Key Concepts Learned

### /proc filesystem
A virtual filesystem in Linux that exposes live kernel data as readable files. Not real files on disk — the kernel generates the content on the fly when you read them. Attackers use /proc because reading files doesn't execute commands and is harder to detect than running tools.

### try/except blocks
Each data collection step is wrapped in its own try/except. If one fails, the error is recorded and the technique continues collecting everything else. This makes the simulation resilient — a partial result is better than no result.

### situational awareness
The first thing an attacker does after landing on a machine. Collecting system info tells them what OS and architecture they're on, what version of tools they can run, how much memory is available, and how long the machine has been up.

### aarch64
The ARM 64-bit architecture used by the Raspberry Pi 5. Different from x86_64 (Intel/AMD). Knowing the architecture is critical for an attacker — binaries compiled for x86 won't run on ARM.
