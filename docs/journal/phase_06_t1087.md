## What T1087 Collects

| Field | Source | Notes |
|---|---|---|
| username | /etc/passwd field 0 | the account name |
| uid | /etc/passwd field 2 | root is 0, regular users start at 1000 |
| gid | /etc/passwd field 3 | primary group ID |
| home | /etc/passwd field 5 | home directory path |
| shell | /etc/passwd field 6 | login shell — /bin/bash means interactive user |
| account_count | calculated | total accounts found — returned 35 on the Pi |

---

## Key Concepts Learned

### /etc/passwd
A plain text file on every Linux system listing all local user accounts. Readable by any user — no special permissions needed. Each line has 7 colon-separated fields.

### System accounts vs user accounts
Most accounts in /etc/passwd are service accounts created by the OS for running background processes (www-data, daemon, root). Real human users typically have UIDs of 1000 or above.

### Login shell
The last field in /etc/passwd. If it's `/bin/bash` or `/bin/sh` the account is interactive — a human can log in with it. If it's `/usr/sbin/nologin` or `/bin/false` the account is a service account and cannot be used to log in.

### Why attackers care about /etc/passwd
It reveals the full list of accounts, which ones are interactive, where home directories are, and which UIDs exist. All of this informs decisions about privilege escalation and lateral movement.
